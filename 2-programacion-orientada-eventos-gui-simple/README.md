# Demo de programacion orientada a eventos

Esta GUI es demasiado sencilla, pero su enfoque es para demostrar los conceptos fundamentales de la programacion orientada a eventos.

## Objetivos del demo

- Demostrar la diferencia entre programacion orientada a eventos y programacion imperativa.
- Demostrar el uso de lambdas y event listeners.
- Demostrar el uso de swing para crear GUIs.
